# Proyecto de prueba técnica Rick And Morty

## Instalación de dependencias
Comando para instalación de dependencias.
``` shell
npm install
```

## Uso en desarrollo

EL siguiente comando levanta el proyecto para su desarrollo.

``` shell
npm run dev
```

## Despliegue a producción

Comando que generan los archivos finales de producción. Crea un directorio llamado `dist` que contiene todo lo necesario para subir el proyecto a un servidor.

``` shell
npm run build
```


Comando para visualizar el projecto final usando el siguiente comando.

``` shell
npm run preview
```

## Variables de entorno

Archivo `.env.dev` utilizado solo para ambiente de desarrollo, crear su archivo para su ambiente productivo basado en `.env.dev`.
